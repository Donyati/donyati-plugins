# /donyati-platforms — List Available Platforms

Use the `list_platforms` MCP tool to see every platform Donyati has expert coverage for, with current article counts.

## Usage

```
/donyati-platforms
```

No arguments. Returns the full live list.

## When to Use

- Before `/donyati-ask` or `/donyati-knowledge` if you're unsure of the platform slug
- To answer "which platforms do we cover?" for a sales conversation
- To check coverage depth (article count) when scoping a deliverable
